# 차트 종류 고르기

숫자는 계산 코드가 표에서 읽은 값을 쓴다("410만 건" → 값 410, 단위 "만 건"). 이 문서는 종류와 계열을 고르는 규칙만 다룬다.

## 고르는 규칙

| 데이터 | 차트 | 과제 파일에 넣는 방식 |
|---|---|---|
| 시간 흐름(연도·월) 한 가지 값 | 꺾은선 또는 세로 막대 | PPT 차트 |
| 항목 비교, 이름이 긴 항목 | 가로 막대 | PPT 차트 |
| 합계 안의 구성(예산 항목) | 누적 막대. 항목 5개 이하이고 합이 100%일 때만 원 | PPT 차트 |
| 단위가 다른 두 값(건수와 비율) | 막대+꺾은선 | 그림(PNG) + 데이터 표 |

- PPT 차트는 PowerPoint에서 값과 모양을 바로 고칠 수 있다. 검토회의 뒤 숫자가 바뀌는 일이 많으므로 PPT 차트를 먼저 고른다.
- 막대+꺾은선은 PPT 차트로 만들 수 없어 그림으로 넣는다. 단위가 다른 두 값을 따로 차트 2개로 나누는 방법도 함께 제안한다(둘 다 PPT 차트로 넣을 수 있다).
- 단위가 다른 값을 한 축에 섞지 않는다. 작은 값이 바닥에 붙어 보이지 않기 때문이다.

## 제목과 강조
- 제목은 표 제목을 그대로 쓴다. 결론을 담은 제목(예: "이용 건수 급감")은 쓰지 않는다. 해석은 응시자의 몫이다.
- 강조(한 막대만 진하게)는 이용자가 요청할 때만 한다. 강조도 응시자의 판단을 이끈다.
