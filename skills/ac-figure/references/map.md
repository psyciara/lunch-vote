# 지도 항목 뽑기

자료 글 전체에서 지도에 넣을 항목을 뽑아 지도 편집기의 초안을 만든다.

## 뽑는 항목
지도 편집기의 범례 항목 이름을 그대로 쓴다. 범례 항목은 관리자가 정하므로(포털 양식·구조 관리), 목록에 없는 종류가 나오면 가장 가까운 항목을 쓰고 "가정"에 적는다.

| 범례 항목 | 자료 글의 단서 |
|---|---|
| 후보지 | "후보지", "부지", "대상지", "A안·B안" |
| 주요 시설 | 역, 청사, 학교, 병원, 대여소처럼 이름이 있는 시설 |
| 주요 도시 / 지역명 | 시·군·구·동 이름 |
| 일반도로 / 고속도로 / 철도 / 하천 | "○○로", "고속도로", "○호선", "○○천·강" |
| 사업 구역 경계 / 공원·녹지 / 하천·수면 / 규제·보호 구역 | "사업 구역", "공원", "저수지", "보호구역·개발제한구역" |

## 위치 정하기
- 글에 위치 관계(북쪽, 건너편, 2km 떨어진)가 있으면 그대로 따른다. 거리는 축척으로 맞춘다.
- 위치 관계가 없으면 겹치지 않게 놓고 "가정: 위치를 자료에 없어 정함"으로 적는다.
- 이름이 없는 대상(예: "인근 하천")에 이름을 붙이면 가정이다.

## 확인할 것
- 후보지 사이 거리, 시설까지 거리가 평가자가이드의 정답 근거라면, 지도에 거리를 적지 않는다(공통 규칙 1).
- 결과의 "가정" 줄에 가정 항목을 빠짐없이 적는다. 포털은 가정 항목을 확인받기 전에는 지도를 넣지 않는다.
