# 그림 장면 설명 쓰기

이미지 생성 모델에 넘길 장면 설명을 쓴다. 모델은 글자, 숫자, 실존 대상을 잘못 그리기 쉬우므로 그런 것이 들어갈 여지를 없앤다.

## 쓰는 법
- 한 문장에 장면 하나: 장소의 종류, 중심 대상, 상태, 시간·날씨.
- 자료 글에 나온 사실만 쓴다. 예: 기사에 "고장 난 자전거만 남아 있다"가 있으면 "대여소에 고장 난 자전거가 줄지어 서 있다".
- 사람은 뒷모습이나 멀리 있는 모습으로 쓴다. 얼굴을 알아볼 수 없게 하기 위해서다.
- 간판, 현수막, 표지판, 화면처럼 글자가 들어갈 물건은 쓰지 않는다.
- 느낌은 이용자가 고른 값(보도 사진 / 일러스트 / 단순한 그림)을 따른다.

## 예
- 자료 글: "시민들은 '빌리러 가면 고장 난 자전거만 남아 있다'고 말한다."
- 장면 설명: "흐린 오후 도심 자전거 대여소, 바퀴가 빠지거나 체인이 늘어진 공영자전거 여러 대가 거치대에 줄지어 서 있다. 멀리 지나가는 시민의 뒷모습. 간판과 글자 없음."
