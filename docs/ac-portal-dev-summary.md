## 2. 데이터

**자리 표기** — 항목 본문 안의 한 줄이 그림 자리 하나다. 넣기·옮기기·빼기는 이 줄을 넣고 옮기고 지우는 것이므로 기존 수정 기록·되돌리기가 그대로 적용된다.

```
[그림] 제목: 설명      ← 그림. 제목에 "지도·위치도·배치도"가 있으면 지도
[차트] 제목            ← 차트
```

**자리에 넣은 결과** (프로젝트에 자리마다 저장, 키 = 항목 ID + 제목)

| 종류 | 저장할 것 | 쓰임 |
|---|---|---|
| 그림 | 고른 그림 파일, 느낌, 비율 | [다시 만들기] 시 같은 설정으로 다시 생성 |
| 올린 파일 | 원본 파일 | 그대로 넣음 |
| 지도 | 작업 파일(JSON: 제목, 범례·축척·방위표 표시, 1km당 길이, 항목 목록[종류, 이름, 근거=원고/가정, 가정 내용, 이름 표시, 좌표]) + 렌더링한 SVG | [다시 만들기] 시 편집 상태 그대로 열기 |
| 차트 | 종류, 제목, 열 이름, 행 값, 단위, 보여 줄 계열, 강조 행, 원본 표 이름 | PPT 차트 생성, [다시 만들기] |

**관리자 양식** (포털 전체 설정): 지도 범례 항목(키, 종류=지점/선/면, 이름, 색, 사용 여부), 차트 계열 색 4개, 차트 글꼴, 그림 기본 느낌·비율.

## 3. 코드로 지켜야 할 규칙

아래는 AI 지침에만 맡기지 말고 코드에서 막는다. 모델이 지침을 어겨도 결과가 틀리지 않게 하기 위해서다.

| 규칙 | 구현 방법 |
|---|---|
| 지도의 "가정" 항목을 확인하기 전에는 넣지 않는다. | 가정 항목이 1개 이상이면 확인 체크 전까지 [이 지도 넣기] 비활성. 확인 뒤 가정 항목이 새로 생기면 체크를 푼다. |
| 차트 숫자는 모델이 옮겨 적지 않는다. | 표의 숫자·단위는 계산 코드가 pptx에서 읽는다("410만 건" → 410, 단위 "만 건"). |
| 섞인 차트는 PPT 차트로 만들지 않는다. | 막대+꺾은선은 PNG + 데이터 표로 내보낸다. 나머지 5가지는 python-pptx 차트로 만든다. |
| 새 자리를 만든 직후 만들기를 취소하면 빈 자리를 뺀다. | 방금 만든 자리에 결과가 없으면 창을 닫을 때 그 줄을 지운다. |
| 바뀐 부분 보기 중에는 넣지 않는다. | 넣기 줄과 [차트로 만들기]를 비활성. |
| AI 자리 제안은 한 자료에 2개까지(이미 있는 그림 포함). | 모델 결과를 받은 뒤 코드로 한 번 더 자른다. |

| 지도 초안 | 평가과제 자료 글 전체, 사용 중인 범례 항목 | 지도 항목 목록(작업 파일 형식) | references/map.md |

## 5. 서버 구성 (명세 8장 중 이 기능 관련)

| 역할 | 후보 | 비고 |
|---|---|---|
| 이미지 생성 | FLUX 계열, Stable Diffusion 계열 등 사내 설치 모델 | GPU 필요. 상업적 이용이 가능한 사용권인지 확인 |
| 지도 편집기 | 포털 안에 직접 구현(SVG) | PNG·SVG·작업 파일(.json) 저장 |
| 차트 | python-pptx 차트 기능, 미리보기는 SVG | 섞인 차트는 PNG |
| 표 읽기 | python-pptx | 그룹 도형 안 표와 차트 숫자도 읽는다 |

## 6. 시안에서 확인한 것과 남은 것

**확인한 것** (데스크톱 1366px, 휴대폰 390px)
- 넣기 줄 → 자리 고르기 → 만들기 창, Esc·취소, 빈 자리 빼기
- AI 자리 제안의 반영·다른 안·반영 안 함·모두 반영, 정답 노출로 제안하지 않은 이유 표시
- 지도 편집기: 그리기·옮기기·꼭짓점 고치기·키보드·실행 취소·내보내기·작업 파일 열기·가정 확인
- 차트: 표 읽기, 종류 전환, 직접 고치기, 넣은 뒤 다시 열기
- 관리자 양식 변경이 지도 팔레트·차트 색에 바로 반영됨
- 화면 오류와 가로 넘침 없음

**시안이 흉내만 내는 것** (실제 구현 필요)
- AI 응답 전부(자리 제안, 지도 초안, 말로 고치기), 그림 생성, pptx 읽기·쓰기, PPT 차트 생성

**확인하지 못한 것**
- 내보내기 파일 이름이 한글일 때: 테스트 브라우저(헤드리스 Chromium)에서는 이름이 "download"로 바뀌었다. 실제 Chrome·Edge에서 한글 이름이 유지되는지 확인이 필요하다.

**결정이 필요한 것** (명세 9장)
- 사내에 설치할 언어 모델과 이미지 생성 모델
- 막대+꺾은선 같은 섞인 차트를 PPT 차트로 넣는 시기(차트 XML 직접 처리)
